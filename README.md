# APACHE NETBEANS LINUX INSTALL

To install Apache NetBeans 31 with Oracle JDK 26, execute the following commands:

```shell
chmod +x install.sh
./install.sh
```

To uninstall:

```shell
chmod +x uninstall.sh
./uninstall.sh
```
